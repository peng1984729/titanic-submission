```python
df["Embarked"] = df["Embarked"].fillna(df["Embarked"].mode()[0])
```

```python
df["FamilySize"] = df["SibSp"] + df["Parch"] + 1
```

```python
X = df.values.astype(np.float32)
```

```python
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size = 0.2, random_state = seed)
```

将$X，y$按比例随机划分为训练集和测试集，并分开做标准化，归一化处理。

注意：训练集和测试集必须分开标准化与归一化处理，不然会互相影响，可能导致测试集上正确率虚高。

## 4. Dataset，DataLoader

```python
class MyDataset(Dataset):
    def __init__(self, X, y):
        self.X = torch.from_numpy(X)
        self.y = torch.from_numpy(y)
    def __len__(self):
        return len(self.y)
    def __getitem__(self, idx):
        return self.X[idx], self.y[idx]
```

首先将$X，y$转化为$torch$的$tenso$r类型，方便后来求导。

```python
train_loader = DataLoader(MyDataset(X_train, y_train),
                          batch_size = 32, shuffle = True)
test_loader = DataLoader(MyDataset(X_test, y_test),
                          batch_size = 32, shuffle = False)
```

使用$DataLoader$每次从$Dataset$中取出$batch\_size$组数据，训练集中数据需要随机取出。

## 5. MLP

```python
class MLP(nn.Module):
    def __init__(self, in_dim, hd = 16):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(in_dim, hd),
            nn.ReLU(),
            nn.Linear(hd, hd // 2),
            nn.ReLU(),
            nn.Linear(hd // 2, 1)
        )
    def forward(self, x):
        return self.net(x)
```

$in\_dim$表示每次输入进$MLP$中的数据量，$hd$为$hidden$的缩写即为隐藏层第一层的数据量。

我的设计是$In\_dim \rarr 16 \rarr 8 \rarr 1$总共4层。

其中$Linear$为线性函数$y = w·x + b$这$nn.Linear$即为加权求和。

其中$w$为权重，$b$为偏置，这两个即为我们需通过机器学习调整的核心参数。

$ReLU$为简单激活函数，$\text{ReLU}(x) = \max(0, x)$。

## 6. 损失函数

```python
loss_fn = nn.BCEWithLogitsLoss()
```

$BCELoss$ 需要手动先 $sigmoid$。问题是：当 $logit$ 很大或很小时，$sigmoid$结果会非常接近 0 或 1，再取对数时会出现**除以接近0的数**，数值不稳定，容易出错。

$BCEWithLogitsLoss$ 把 $sigmoid$ + 交叉熵 两步**合并成一个数学公式**，绕开了这个不稳定的中间步骤，**数值更稳**，所以我们二分类使用它。

## 7. 优化器

```python
opt = torch.optim.Adam(model.parameters(), lr = 1e-3)
```

$model.parameters()$：把模型里所有可学习的参数（$w$ 和 $b$）交给优化器管理

$lr=1e-3$：学习率 = $0.001$，每次更新的步长。

```python
pred = model(xb).squeeze(1)
loss = loss_fn(pred, yb)
opt.zero_grad()
loss.backward()
opt.step()
```

优化器的作用：损失算出来、反向传播求出梯度后，优化器根据梯度去更新参数，让下一次预测更准。

$opt.zero\_grad()$ ：清空梯度。

$loss.backward()$：从$loss$出发回溯，求出每个参数的梯度。

$opt.step()$ ：更新参数。

所以我们只需循环这几步就可以了。

## 9. 心得体会：

预测的本质是通过设计函数并调整来拟合数据，最终达到预测的效果。

$MLP$即将特征值即原始数据通过设计的函数转化为概率。再将此概率与标签y进行对比，得到$loss$。

接着使用优化器不断调整函数参数，达到提高预测准确率的效果。
